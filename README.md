# VEDPRAKASH — Ideas to Intelligent Solutions

Personal brand site for AI websites, automation systems, and custom bots.

**Build · Automate · Grow**

## Pages

- Home
- About
- Services
- Projects (with case studies)
- Tools
- Testimonials
- Contact — briefs save on-device and can be downloaded as JSON

## Stack

React 19 · TanStack Start · Tailwind CSS v4 · Lucide

## Run

```bash
npm install
npm run dev
```

Opens at `http://localhost:8080`.

Site copy lives in `src/data/content.ts`. Contact briefs are stored in the browser (`localStorage` key `kunal-inquiries`).
