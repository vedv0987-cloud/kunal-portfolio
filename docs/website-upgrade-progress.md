## The pattern found in nearly every phase

Every asset depicting a *specific real entity* — a named client, the
site's own identity, or a factual claim — turned out to have something
fabricated baked into the pixels: an invented client logo (6+ instances
across Work/About/Case-study), the wrong name (About hero, Contact email
card), a real third-party trademark reproduced without authorization
(Claude, twice), invented statistics (case-study results, global-map
banner), or a documented typo (2 CTA banners, both already in
`qa-redo.json`). Assets depicting *generic* scenes, categories or process
steps — architecture photography, industry photos, workflow step cards —
were consistently clean. Every phase checked each asset individually
before using it rather than trusting the folder name.
